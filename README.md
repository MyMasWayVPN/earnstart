# Cara Pakai

## Jalankan

### Windows CMD

```bat
node run.js
```

### Termux

```bash
pkg update && pkg upgrade -y
pkg install nodejs
node run.js
```

## Langkah

1. Jalankan `node run.js`
2. Buka link yang tampil
3. Ambil key dari link tersebut
4. Masukkan key ke terminal
5. Masukkan `Query_ID`
   Jika Android, gunakan Kiwi Browser, install extension Bypass Telegram Web, buka web app bot, lalu salin `Query_ID` extension pada atau data query yang dibutuhkan.
6. Pilih mode:

```txt
1 = cek sekali
2 = auto claim
```

## Hentikan Script

```txt
Ctrl + C
```
