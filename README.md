# Cara Pakai

### Windows CMD

##### -- Wajib Di Install

- Git Bash
- Node.js 18+
- Browser

```bat
git clone https://github.com/mymaswayvpn/earnstart
cd earnstart
node run.js
```

### Termux
##### -- Wajib Di Install
- Termux
- Node.js
- Kiwi Browser
- Extension Bypass Telegram Web

```bash
pkg update && pkg upgrade -y
pkg install git
git clone https://github.com/mymaswayvpn/earnstart
cd earnstart
pkg install nodejs
node run.js
```

## Langkah

1. Jalankan `node run.js`
2. Buka link yang tampil
3. Ambil key dari link tersebut
4. Masukkan key ke terminal
5. Masukkan `Query_ID`
   Jika Android, gunakan Kiwi Browser, install extension Bypass Telegram Web, buka web app bot, lalu salin `Query_ID` extension pada atau data query yang dibutuhkan.
6. Pilih mode:

```txt
1 = cek sekali
2 = auto claim
```

## Hentikan Script

```txt
Ctrl + C
```
